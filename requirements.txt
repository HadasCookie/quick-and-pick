## Setup Instructions
1. Install Python (3.8 or higher)
2. Install Node.js (16.x or higher)
3. Install Chrome browser and ChromeDriver (for testing)
4. Clone the repository
5. Contact project team for:
   - Database password
   - IP whitelist access to GCP database
   - API keys (if testing full functionality)

6. Install Python backend dependencies:
   cd quick-and-pick
   pip install -r requirements.txt

7. Install frontend dependencies:
   npm install
   # This will install the current dependencies from package.json:
   # - React 19.1.1, React DOM 19.1.1, React Router DOM 7.7.1
   # - @react-google-maps/api, axios, js-confetti
   # - Development tools: testing libraries, react-scripts

8. Configure environment variables:
   - Create .env file in root directory (for React)
   - Create .env file in server directory (for Python)
   - Add provided credentials

9. Start the application:
   - Backend: python -m src.server (runs on http://localhost:5000)
   - Frontend: npm start (runs on http://localhost:3000)

10. Run tests (optional):
    - Python tests: pytest tests/
    - Frontend tests: npm test

## Database Schema (Pre-configured in GCP)
# The database is already set up with the following tables:
- users: User authentication and preferences
- products: Product catalog with categories (50,000+ items)
- shopping_lists (user_lists): Saved user shopping lists
- stores: Supermarket information and locations
- store_prices: Product prices per store (millions of records)
- price_drop_alerts: User price monitoring subscriptions

## API Endpoints
# Authentication
- POST /api/register - User registration
- POST /api/login - User login
- POST /api/change-password - Change user password

# Products & Lists
- GET /api/products - Get all products
- POST /api/save-list - Save shopping list
- GET /api/user-lists - Get user's shopping lists
- GET /api/user-last-list - Get user's last shopping list
- POST /api/update-list-name - Update list name
- POST /api/update-list-price - Update list price
- POST /api/update-list-favorite - Toggle favorite status

# Store Comparison
- GET /api/find-nearby-stores/:listId - Find nearby stores
- POST /api/evaluate-supermarkets/:listId - Compare store prices

# Recommendations & Alerts
- GET /api/recommend-items - Get AI product recommendations
- POST /api/subscribe-to-price-drop - Subscribe to price alerts
- GET /api/user-alerts - Get user's price alerts
- DELETE /api/delete-alert/:id - Delete price alert

# Communication
- POST /api/send-list-sms - Send list via WhatsApp
- GET /api/suggestions - Get product suggestions from external APIs

# User Management
- POST /api/update-preferences - Update user preferences
- POST /api/close-account - Deactivate user account
